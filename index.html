03 — ALGORITHMS

The logic behind the work.

01 O(G · n · L)

Genetic Algorithm

Breeds a population of candidate solutions toward the best one. Fitness decides who survives, crossover mixes their genes, and mutation keeps the search from settling too early.

Optimization Evolutionary
02 O(n · m · k)

Ant Colony Optimization

Finds routes the way ants find food. Every path leaves a pheromone trail behind, the strongest trails grow, and the weak ones evaporate away.

Swarm Routing
03 O(n log n)

Greedy Earliest Deadline First

Always runs the task that is due soonest. It is the fast, simple rule that decides what gets done next in the Smart Task Manager.

Greedy Scheduling
04 O(V + E)

Topological Sort

Orders a dependency graph so every task comes after the ones it needs. A cycle in the graph means the plan cannot be scheduled at all.

Graph Dependencies
05 O(n · B)

Dynamic Programming

Solves the take-or-skip problem by remembering the answer to every subproblem, so no combination is ever evaluated twice.

Memoisation Knapsack
06 O((V + E) log V)

Dijkstra's Shortest Path

Grows outward from the start node, always expanding the cheapest frontier first, and settles each node at its true shortest distance.

Graph Shortest Path
