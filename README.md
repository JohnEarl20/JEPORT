# Portfolio Website - John Earl Conde

## Setup
1. Save your profile photo as `profile.jpg` inside this `portfolio/` folder.
2. Open `index.html` in your browser — that's it!

## Customize
- **Name / Info** → Edit `index.html`
- **Colors / Font** → Edit `style.css` (change `--primary` and `--secondary` in `:root`)
- **Skills & Projects** → Edit the sections in `index.html`
- **Social Links** → Update the `href` attributes in the social-links and contact sections

## Files
- `index.html` — main page
- `style.css` — all styling
- `script.js` — typing animation, scroll effects, nav highlight
- `profile.jpg` — your photo (add this yourself)
